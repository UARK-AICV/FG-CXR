# Historical IAI source

This directory contains historical source derived from
[UARK-AICV/IAI](https://github.com/UARK-AICV/IAI), the implementation of the
WACV 2024 paper **Decoding Radiologists' Intense Focus for Accurate CXR
Diagnoses: A Controllable & Interpretable AI System** by Trong Thang Pham,
Jacob Brecheisen, Anh Nguyen, Hien Nguyen, and Ngan Le.

The upstream repository does not currently declare a software license. These
files therefore retain their original copyright and are not covered by the
root FG-CXR MIT License. Permission from the copyright holders may be required
for reuse or redistribution.

The supported FG-CXR reproduction is implemented under `fgcxr/`; this
historical directory is retained only for technical provenance and attribution.
